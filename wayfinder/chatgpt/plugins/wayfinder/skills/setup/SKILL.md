---
name: setup
description: Collect or revise Wayfinder travel preferences when a traveler first sets up Wayfinder or asks to change their defaults.
---

Ask for these three preferences together. Reuse values the traveler already supplied.

- **Home Airport** — IATA code or city and airport name. Confirm which airport if the
  answer is ambiguous.
- **Preferred Currency** — three-letter currency code, such as CAD or EUR.
- **Walking Pace** — relaxed, moderate, brisk, or a custom pace. Let the traveler
  specify a maximum walking leg or daily distance if they wish.

Accept skipped fields. If pace is skipped, use a moderate pace as a labeled planning
estimate. For budgets, show local currency until the traveler chooses a conversion
currency. A home airport is optional for planning within a city. Summarize confirmed
preferences and use them in the current conversation. Only report that preferences were
saved across conversations if the host confirms persistence.
